# smeta-master-catalog

Публичный издатель обновлений базы товаров и официальных ориентиров для Android-приложения
«Смета мастера».

## Что публикуется

Каждый выпуск GitHub Releases содержит:

- `catalog-YYYY-MM-rN.json.gz` — полный системный каталог и ориентиры;
- `latest.json` — манифест для ручной проверки обновлений приложением.

Право покупки относится к `YYYY-MM`. Новая ревизия `rN` того же месяца не требует новой
покупки. Файлы публичны, не шифруются и не содержат DRM.

## Источники и правила

- Росстат 9-КС — основной источник средних цен строительных материалов.
- ЕМИСС/НЦСЭД `37055.csv.gz` загружается как резервный источник, но может заполнить только
  отсутствующую позицию и только если его период свежее Росстата.
- Сопоставление выполняется только по явному ОКПД2-коду, ожидаемой единице и списку aliases из
  [`data/mappings.json`](data/mappings.json). Нечёткое угадывание запрещено.
- Отрицательные и нулевые цены, неизвестные единицы, дубликаты, старые периоды и падение покрытия
  ниже 70% останавливают публикацию.

В `manifest.sha256` хранится SHA-256 канонической полезной нагрузки `{items,references}`. Это
устраняет невозможную самоссылку хеша на манифест внутри того же архива и всё равно обнаруживает
повреждение или подмену данных после распаковки.

## Локальная проверка

```powershell
npm install
npm test
npm run lint
npm run build
$env:RELEASE_PERIOD="2026-07"
npm run catalog:build
```

Если локальная цепочка сертификатов Росстата не проходит проверку Node.js, файлы можно скачать
отдельно и передать только этому запуску:

```powershell
$env:ROSSTAT_PAGE_FILE="rosstat-price.html"
$env:ROSSTAT_WORKBOOK_FILE="rosstat-materialy.xlsx"
$env:EMISS_CSV_FILE="emiss-37055.csv.gz"
npm run catalog:build
```

GitHub Actions запускается по понедельникам и вручную. Если полезная нагрузка не изменилась,
новый релиз не создаётся.

## Лицензии данных

Ссылки на источник и условия использования включаются в каждый манифест. Открытые данные Росстата
можно повторно использовать, в том числе коммерчески, при сохранении ссылки на источник.
Данные НЦСЭД публикуются с указанием CC-BY 4.0 на странице набора.
